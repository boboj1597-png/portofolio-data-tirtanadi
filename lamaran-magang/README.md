# Template Berkas Lamaran Magang — Perumda Tirtanadi

> `lamaran-magang/README.md` — Panduan folder template surat lamaran, CV, dan proposal magang Kalek untuk Perumda Tirtanadi.

> Folder contoh ini berisi TEMPLATE surat dan CV yang merujuk ke portofolio ini.
> Silakan salin (Save As), isi bagian bertanda `[...]`, lalu ekspor ke PDF untuk dilampirkan bersama surat resmi kampus.
> File template tidak perlu dihapus dari repo — perekrut justru menilai kesiapan administrasi kamu.

## Daftar File Template

| File | Fungsi | Cara Pakai |
|------|--------|------------|
| `Surat_Lamaran_Magang_Tirtanadi_TEMPLATE.md` | Surat lamaran 1 halaman ke Direksi/SDM | Isi tanggal, nama, NIM, kontak, periode magang, pilihan penempatan |
| `CV_Kalek_TEMPLATE.md` | CV ATS 1 halaman Data Analyst / Admin | Isi email final (samakan 1 alamat), LinkedIn, pengalaman, pendidikan |
| `Proposal_Magang_Singkat_TEMPLATE.md` | Proposal 1-2 halaman untuk kampus & perusahaan | Isi tujuan, ruang lingkup 3 proyek, jadwal mingguan, output |
